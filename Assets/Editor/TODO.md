# Texture Tools — UX改善案（Unity 2019.4 / IMGUI）

## 1) レイアウトとナビゲーション

### A. 「レシピ」タブを先頭に
- **1クリック実行のプリセット**  
  - PNG変換＋元削除  
  - Invert（全チャンネル）  
  - Normal: G反転  
  - Normal: Strength=1.5  
  - マスク統合：ORM / HDRP / MRA プリセット
- **下位タブ：**「詳細（カスタム）」…現行の詳細UIを表示  
  → 頻出操作＝ワンアクション、個別調整＝詳細タブ

### B. 2カラム構成
- **左：** 操作パネル（入力、パラメータ、実行ボタン）  
- **右：** ライブプレビュー（小サイズ）
  - Before / After トグル
  - 表示モード切替：RGB / A / Normal（法線ビジュアライズ）

### C. セクションの折りたたみ（Foldout）
- 対象：**PNG変換 / Invert / 法線 / マスク統合**
- 最終開閉状態を `EditorPrefs` に保存して復元

## 2) クリック削減のための挙動

### A. 自動入力 / 自動検出
- **Project で選択中のテクスチャ**を、対象欄が空なら自動セット
- **マスク統合のドラッグ&ドロップ割当（ヒューリスティクス）**
  - `ao|occlusion` → **R**
  - `rough|roughness|smoothness` → **G**（必要なら **Invert 自動ON**）
  - `metal|metallic` → **B**
  - `alpha|opacity` → **A**

### B. 保存先の簡略化
- 「保存先ベースパス」ではなく、次の選択肢に集約：
  - **同フォルダに `_proc` サフィックスで保存**（デフォルト）
  - **同名上書き**チェック
  - **フォルダを開く**ボタン
- → 入出力設定を 1〜2 クリックで完結

### C. 実行ボタンの集約
- 各セクションに **「適用」ボタン**を1つだけ配置
- **Enterキー**で実行（`GUI.SetNextControlName` + `Event.current` の処理）

### D. GPU自動判定
- 「GPUを使用」：**自動（推奨） / GPU固定 / CPU固定** の 3 段切替
- → 毎回の手動切替を不要に

## 3) マスク統合のUX

### A. 出力チャンネル行（4行の表形式）
各行＝**出力 R / G / B / A**。横並びで以下を配置：
1. **入力テクスチャ**（ObjectField＋ドロップゾーン）
2. **チャンネル選択**（R / G / B / A のセグメントボタン）
3. **反転**（トグル）
4. **プレビュー**（16×16、選択チャンネルのグレイスケール）
5. **クリア**（×）

右上に**プリセットボタン**（ORM / MRA / MAO など）を配置。

### B. プリセット（1クリック）
| プリセット | 出力R | 出力G | 出力B | 出力A |
|---|---|---|---|---|
| **ORM** | AO | Roughness（必要なら Invert） | Metal | 未使用 |
| **MRA** | Metal | AO | 未使用 | Smoothness = 1 − Roughness |
| **MAO** | Metal | 未使用 | AO | 未使用 |

- **Unreal向け**の並びも用意（必要に応じて）
- **自作プリセット**を `ScriptableObject` で保存/読込

### C. デフォルト値の明示
- 入力未指定時の出力デフォルト：**R=0, G=0, B=0, A=1**（UIに小さく注記）

---

## 4) 法線ツールのUX
- **「Gを反転（OpenGL/Y）」をデフォルトON**
- 強度：**定数ボタン（0.5 / 1.0 / 1.5 / 2.0）**＋スライダー
- 右側プレビューに**法線ベクトル可視化（矢印オーバーレイ）**の ON/OFF

---

## 5) フィードバックと安全性
- **進捗表示：** `EditorUtility.DisplayProgressBar`（大きいテクスチャ時）
- **完了トースト：** `ShowNotification` / `SceneView.ShowNotification`  
  例：「保存しました：`xxx.png`」
- **元削除：** 可能なら**ゴミ箱へ移動**＋**「取り消し不可」**の赤字ラベル
- **エラー時：** 最前面ダイアログ表示＋コンソールに詳細ログ
